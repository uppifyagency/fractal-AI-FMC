2. Live simulator — pilota il razzo via FMC

Cono FMC: traiettorie oro = lineage vincente, azzurre = alternative scartate dal cloning, rosse = walker morti. Punti finali = "horizon" del cono. Razzo giallo = stato vero. Verde = goal (rispawna ad ogni cattura). Tracciato bianco = path effettivo.

3. Parametri FMC

Common Sense mode (α=0)

Setta α=0 (clic "α=0 mode"): il razzo ignora il goal, cerca solo di restare vivo. Pattern paper §6.3: "never crashes". È il test diretto del claim di Sergio sul drone autopilot. Se il razzo svolazza senza schiantarsi, FMC funziona su free-flight. Se cade, FMC ha un limite strutturale.

Cosa è cambiato vs rocket.html

1. Reward composta moltiplicativa R = alive × clearance × (1 + progress)
2. Time horizon default M=40 (vs 15) — lookahead 1.6s
3. Action continua sampled da gaussiana con bias counter-gravity
4. Distance metric pesata per canale (pos, vel, attitude)
5. Init-action persistence: σ piccolo nei primi 4 tick
6. ESS-adaptive cloning (skip se ESS > 0.7·N)
