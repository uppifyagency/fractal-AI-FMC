# Fractal AI Collaboration

## Posted by Sergio Hernandez on Friday, 25 December 2015

Controlling individual agents intelligently using thermodynamic concepts is achievable through fractal decision trees. However, managing groups of agents presents greater complexity. Previously, multiple agents evolved in shared environments by treating others as environmental obstacles rather than collaborators.

The author presents genuine swarm intelligence that orchestrates agent groups as unified entities. A group of rockets, for instance, can behave intelligently as a collective structure rather than independent individuals following shared objectives.

## Core Concept: Hierarchical Intelligence

The key insight involves treating a group of intelligent agents as itself comprising a "higher-level agent" with distinct goals. This creates "a fractal tree of intelligence layers" where fingers coordinate as a hand, hands function as an octopus, and multiple octopuses respond to collective instructions like retrieving objects.

The algorithm decomposes complex problems into smaller components, enabling individual actions across all agents while maintaining cohesive group behavior.

## Implementation Approaches

**Star Formation Model:** Agents maintain preset distances, connected by simulated "causal entropic forces" (not physical springs). These forces encourage agents toward preferred positions. Drawbacks emerged when rigid formations encountered obstacles.

**Wave-Based Potential:** Using interference patterns from water waves creates an "amorphous crystal net." Each agent generates circular zones of varying potential using the mathematical function: P = (0.8 + (1-0.8) × ((Sin(PI/2×d))² × (2/(d+1))))²

## Future Applications

The author plans implementing group games and eventually controlling complex robots through potential field maximization, making sophisticated collaborative tasks achievable.
